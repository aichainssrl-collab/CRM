# 03 Tech Stack

## Frontend
- **Framework**: Next.js 14 (App Router)
- **Linguaggio**: TypeScript
- **Styling**: Tailwind CSS
- **Componenti UI**: shadcn/ui, Radix UI (ora base-ui/lucide)
- **Data Fetching**: TanStack React Query v5
- **Form & Validazione**: react-hook-form + zod
- **Auth**: Firebase Auth SDK (Client)

## Backend
- **Framework**: FastAPI (Python 3.11+)
- **Linguaggio**: Python
- **Validazione**: Pydantic v2
- **Database Driver**: motor (MongoDB Async)
- **Test**: pytest, pytest-asyncio
- **Auth**: firebase-admin SDK

## Cloud & DevOps
- **Database**: MongoDB Atlas (o istanza locale per dev)
- **Authentication**: Firebase Auth
- **Code**: Cloud Tasks (Google Cloud Platform)
- **Container**: Docker (Dockerfile disponibile per backend)
